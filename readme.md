1. Запуск Win+R (комбинация клавиш). Пишем cmd. Жмём Enter.
2. Пишем команду:
chcp 866
У меня русские символы отображаются нормально, но это лучше выполнить для надёжности отображения ру символов в cmd.
3. Примеры запусков (скомпилированные в exe находятся в папке в директории):
-------------------------------------
- 1: lab1.exe <число> <флаг>
Флаги:
- -h - вывести натуральные числа, кратные x, до 100.
- -p - проверить, является ли число простым или составным.
- -s - вывести шестнадцатеричные цифры числа.
- -e - вывести степени чисел от 1 до 10.
- -a - посчитать сумму от 1 до x.
- -f - вычислить факториал числа.
Примеры:
lab1.exe 7 -p
lab1.exe 20 -h
lab1.exe 5 -f
lab1.exe 10 -a
-------------------------------------
- 2: lab2.exe <эпсилон>
Программа вычисляет e, π, ln(2), √2 и постоянную Эйлера разными способами.
Пример запуска:
lab2.exe 0.01
-------------------------------------
- 3: lab3.exe <флаг>
Флаг -q - решение квадратных уравнений:
lab3.exe -q 0.001 1 -3 2
Флаг -m - проверка делимости первого числа на второе:
lab3.exe -m 12 3
Флаг -t - проверка, могут ли три стороны образовать прямоугольный треугольник:
lab3.exe -t 0.001 3 4 5
-------------------------------------
- 4: lab4.exe <флаг> <входной_файл> [выходной_файл]
Флаги:
- -d - удалить цифры из файла.
- -i - посчитать количество латинских букв в каждой строке.
- -s - посчитать количество специальных символов.
- -a - оставить цифры, а остальные символы заменить HEX-кодами.
- n после дефиса означает, что имя выходного файла указывается вручную.
Примеры:
lab4.exe -nd input.txt output.txt
lab4.exe -ni input.txt letters.txt
lab4.exe -ns input.txt special.txt
lab4.exe -na input.txt hex.txt
Если не указывать n, программа создаст выходной файл автоматически:
lab4.exe -d input.txt
-------------------------------------
- 5: lab5.exe <эпсилон> [x]
Программа вычисляет суммы рядов и интегралы.
Если x не указать, используется значение 0.5.
Примеры:
lab5.exe 0.01
lab5.exe 0.01 0.5
-------------------------------------
- 6: lab6.exe
Флагов и дополнительных параметров нет.
Пример запуска:
lab6.exe
Программа автоматически выполняет несколько математических заданий: проверяет выпуклость многоугольника, вычисляет значение многочлена, среднее геометрическое, степень и корни уравнений.
-------------------------------------
- 7: lab7.exe <флаг> ...
Флаги:
- -a - обработать один файл.
- -r - поочерёдно объединить слова из двух файлов.
Примеры:
lab7.exe -a input.txt output.txt
lab7.exe -r first.txt second.txt result.txt
-------------------------------------
- 8: lab8.exe <входной_файл> <выходной_файл>
Флагов нет.
Программа определяет основание системы счисления каждого числа и переводит его в десятичное значение.
Пример запуска:
lab8.exe input.txt output.txt
-------------------------------------
- 9: lab9.exe <минимум> <максимум>
Программа создаёт случайные массивы в указанном диапазоне, находит минимальный и максимальный элементы, меняет их местами и формирует третий массив.
Пример запуска:
lab9.exe 1 10
Ещё один пример:
lab9.exe -100 100
-------------------------------------
- 10: lab10.exe
Флагов и параметров нет.
Пример запуска:
lab10.exe
После запуска вводим основание системы счисления, затем числа по одному в строке. Для завершения вводим Стоп.
Пример:
10
15
-20
Стоп
Здесь 10 - основание системы счисления, а 15 и -20 эт введённые числа.
